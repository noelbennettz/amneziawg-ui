自架的 AmneziaWG 面板。AmneziaWG 是 WireGuard 的混淆分支，能穿過 DPI 封鎖。 在瀏覽器裡開伺服器、加用戶端，發 .conf、QR 或 vpn://， 即時看流量。單一 image 約 35 MB，不需要 Node、nginx 或 supervisor。

面板做什麼

伺服器、用戶端、匯出與流量，都在一個瀏覽器分頁裡。

一個容器

Go + Fiber 同時提供 API 與前端，Fyne 介面編成 WebAssembly。沒有 Node、nginx、supervisor 或額外資料庫，大約 35 MB。

AmneziaWG 3.1 永遠開啟

標頭保護、隨機 trailer、停用 cookie、junk 封包與 padding 全部內建。標頭金鑰與每個混淆參數自動產生，並與用戶端設定保持同步。

一台主機多個伺服器

每個伺服器有自己的 port、子網、MTU、DNS、endpoint 與混淆參數。在面板新增或修改，容器重啟後會自動把它們帶回來。

用戶端三種匯出

新增、編輯、暫停或排程用戶端。可匯出 .conf、給手機掃的 QR，或給 AmneziaVPN 用的原生 vpn:// 連結。

即時流量

流量與 handshake 圖表、每個用戶端最後的 endpoint、伺服器狀態，面板開著時自動更新。

面板前有登入

12 小時簽章 cookie、每次寫入都要 CSRF token，同時保留 Authorization: Basic，所以 curl -u 腳本照樣能用。審計日誌一個開關。

REST API

面板做的每件事都是同一組登入後方的 HTTP endpoint，可以用腳本自動化，不必手動點。

IPv4 與 IPv6

面板同時監聽兩種位址族別，每個伺服器配一個 ULA /64 與 NAT6；用戶端的 endpoint 與 DNS 清單都接受任一雙棧位址。

需求

一台裝好 Docker 與 Docker Compose 2.24 以上版本的 Linux 主機。

  • Docker Engine 與 Compose 2.24+。compose 檔用到 env_file.required 與 !reset。
  • /dev/net/tun 與 NET_ADMIN。amneziawg-go 在使用者空間執行，不必載入 kernel module，也不用 SYS_MODULE。
  • 一個對外 IPv4 位址。IPv6 是每個伺服器選配；下一段說明 bridge 網路做不到什麼。
  • 兩個主機埠。54845/tcp 給面板，每個伺服器一個 UDP 埠，預設 54844/udp。
docker --version
docker compose version   # 需要 v2.24 以上
ls -l /dev/net/tun

狀態就是一個 volume。伺服器、用戶端設定與 web_config.json 都在 /etc/amnezia；備份這個 volume，換主機時整組搬過去就好。

安裝

一台裝好 Docker 與 Compose 的 Linux 主機。面板會開在 54845 埠。

先算面板密碼的 hash

容器存的是 base64(sha256(密碼))，不是密碼本身。

printf 'your-password' | openssl dgst -binary -sha256 | base64

存成 compose.yaml

把上一步的結果填進 WEB_UI_PASSWORD。最常要改的是位址、port 與 volume：把面板綁在 127.0.0.1，就只有本機的 TLS 代理連得到，其他介面一律關著。每個 key 的意義寫在 DOCS.md，repo 裡另有一份逐行註解的 docker-compose.example.yml。

services:
  app:
    image: ghcr.io/noelbennettz/amneziawg-ui:latest
    restart: unless-stopped
    ports:
      # 把面板綁在單一位址。建議這樣做：本機的 TLS 代理連得到 127.0.0.1，
      # 其他介面則完全連不到這個 port。
      # - "127.0.0.1:54845:54845/tcp"
      - "54845:54845/tcp"   # 面板
      - "54844:54844/udp"   # 第一個 VPN 伺服器
    environment:
      WEB_UI_PORT: "54845"
      WEB_UI_USER: "admin"
      WEB_UI_PASSWORD: "REPLACE_WITH_HASH"
    volumes:
      - data:/etc/amnezia
    cap_add:
      - NET_ADMIN
    devices:
      - /dev/net/tun
    sysctls:
      net.ipv4.ip_forward: "1"
      net.ipv4.conf.all.src_valid_mark: "1"
      net.ipv6.conf.all.disable_ipv6: "0"
      net.ipv6.conf.all.forwarding: "1"
      net.ipv6.conf.default.forwarding: "1"

volumes:
  data:

啟動並登入

然後開 http://your-server:54845/，用步驟 1 的使用者與密碼登入。

docker compose up -d

面板本身是 HTTP。前面請放一層 TLS 反向代理，並設 WEB_UI_SECURE_COOKIE=true（或讓代理送出 X-Forwarded-Proto: https）。

IPv4 與 IPv6

面板與通道都是雙棧；用戶端有沒有 IPv6 上網，取決於 Docker 網路。

  • 預設雙棧。面板同時聽 0.0.0.0 與 [::]；用戶端設定接受 IPv4 或 IPv6 的 endpoint，DNS 也能填任一雙棧位址。
  • 每個伺服器一個 ULA /64 與 NAT6。防火牆腳本按位址族別判斷，只有該族有 default route 且 uplink 有可路由來源時才寫 forwarding 與 masquerade。
  • 一般 Docker bridge 預設沒有 IPv6 上行。Docker 最多只給容器一個 unique local 位址，所以用戶端有 IPv6 通道卻沒有 IPv6 egress，nat6.state 顯示 ula-only。
  • 要讓用戶端上 IPv6，有兩條路。一是替 compose 網路加上對外前綴（如下），二是改用 host network；之後 nat6.state 會變 ok。
# 給 compose 網路一個供應商路由到本機的 global 前綴
networks:
  default:
    enable_ipv6: true
    ipam:
      config:
        - subnet: 2001:db8:1::/64
# 或改用 host network
docker compose \
  -f docker-compose.yml \
  -f docker-compose.host.yml up -d

# 主機上執行一次：
sysctl -w net.ipv4.ip_forward=1 \
         net.ipv6.conf.all.forwarding=1 \
         net.ipv6.conf.default.forwarding=1

對外之前

預設值是保守的；公開主機上必須改的就這幾項。

先改密碼

範例 hash 對應的是 changeme。在 port 對外之前換掉：面板只存 hash、簽 12 小時 cookie，改密碼會同時結束所有 session。

最小權限

容器以 root 執行，因為 awg-quick 與 iptables 在自己的 network namespace 裡需要；它只拿到 NET_ADMIN 與 /dev/net/tun，沒有 SYS_MODULE，除非你要求也不會用 host network。

TLS 與審計

用 Caddy、nginx 或 Traefik 終結 TLS，並設 WEB_UI_SECURE_COOKIE=true。打開 WEB_UI_AUDIT_LOG 會為每次登入與變更寫一行 JSON，保留時間可調。

常見問題

安裝與使用上最常被問的幾件事。

AmneziaWG 跟 WireGuard 差在哪？

加密與速度相同，多了混淆：junk 封包、padding 與改寫的標頭讓 DPI 認不出協定。AmneziaWG 3.0 加入標頭保護，3.1 再加隨機 trailer 並停用 cookie 交換；這個面板預設全部開啟。

哪些用戶端可以用？

官方 AmneziaVPN 5.0.1.5 或更新版，Windows、macOS、Linux、Android、iOS 都有：貼上 vpn:// 或掃 QR。較舊的 AmneziaWG 用戶端請在伺服器表單清掉 RandomTrailers 與 DisableCookies。

怎麼改面板密碼？

用 printf 'your-password' | openssl dgst -binary -sha256 | base64 算出新值，填進 WEB_UI_PASSWORD，重啟容器。改密碼會讓所有 session 立即失效。

一定要 HTTPS 嗎？

容器只提供 HTTP。前面放 Caddy、nginx 或 Traefik 做 TLS；代理在同一台主機時，port 發佈到 host 的 loopback，並設 WEB_UI_SECURE_COOKIE=true 或轉送 X-Forwarded-Proto: https。

為什麼用戶端有 IPv6 卻不能上 IPv6 網站？

一般 Docker bridge 預設只給容器一個 unique local 位址，NAT6 只能轉到 ULA。兩條路：替 compose 網路加上對外前綴（enable_ipv6: true 加 ipam 子網，前綴要由供應商路由到本機，daemon 需開 "ipv6": true 與 "ip6tables": true），或改用 docker-compose.host.yml。API 的 nat6.state 會告訴你是哪一種。

怎麼更新或搬家？

更新用 docker compose pull 再 docker compose up -d；想讓升級變成一個決定，就把 compose 裡的 tag 釘在日期版。搬家只要把 /etc/amnezia volume 複製到新主機再啟動。

小 VPS 或 ARM 跑得動嗎？

image 有 amd64 與 arm64，容器本身約 35 MB。通道在使用者空間，所以不用管主機的 kernel module 版本。

AGPL 在這裡代表什麼？

自架、fork、賣支援都可以。但如果你把修改過的面板當成網路服務給別人用，使用者必須能取得你實際執行版本的原始碼——這就是第 13 條。

AmneziaWG Web UI 是 AmneziaWG 協定的獨立自架面板，與 Amnezia 專案無隸屬關係。 原始碼、完整文件與安全說明都在 repository。
